# Platform Playbook Skill

## Scope

This skill gives agents an understanding of Douyin and Xiaohongshu platform rules, content structure standards, and algorithm logic.

---

## Douyin Platform Rules

### Content Structure Standards (Knowledge-IP)
- **Length**: 60–180 seconds is the optimal range (best completion rate)
- **First 3 seconds**: must have a strong visual or verbal hook (determines whether viewing continues)
- **Pacing**: one information node every 15–20 seconds; avoid overly low information density
- **Ending**: clear CTA (follow / save / comment); last 5 seconds cannot be blank

### Algorithm Logic
- **Core metrics**: completion rate > interaction rate > follow rate (weighting order)
- **Cold start**: first 30-minute data determines the size of the initial traffic pool
- **Tag recommendation**: algorithm identifies content category via subtitles, hashtags, and description keywords
- **Account authority**: consistently stable publishing > burst publishing; recommended frequency: 1–2 pieces per day

### Publishing Standards
- Video format: MP4, resolution ≥ 720p, ratio 9:16
- Cover: on-camera shot + title text overlay (builds trust for knowledge-IP)
- Hashtags: 3–5; do not exceed 5 (over-limit reduces distribution)
- Description: includes 1–2 core keywords; prompts an engagement question

### Violation Risks
- Hard-sell placement (unannounced): suppression / deletion
- Exaggerated numbers (earnings / effects): violates advertising law; deletion + suspension risk
- Competitor disparagement: deletion
- Controversial political / social topics: handle with sensitivity or avoid

## Xiaohongshu Platform Rules

### Content Structure Standards (Knowledge-IP)
- **Note type**: image post (8–12 slides) outperforms video (algorithm currently favours image posts)
- **Title**: includes core keyword, ≤ 20 words, search-friendly, with emotion or number
- **Cover**: large text + high colour contrast; first slide conveys core value immediately
- **Body**: bullet points / paragraphs, emoji per section, total word count 500–1 000 words preferred

### Algorithm Logic
- **Core metrics**: save rate > like rate > comment rate (save is the most important signal)
- **Search traffic**: 60%+ of Xiaohongshu traffic comes from search; keyword layout is critical
- **Recommendation logic**: high-interaction content enters larger traffic pools (similar to Douyin but with a longer cycle)
- **Account authority**: highly vertical, consistently publishing accounts get more recommendation weight

### Publishing Standards
- Image ratio: 1:1 or 3:4 (portrait is more immersive)
- Image count: 6–12 recommended
- Hashtags: 3–5
- Last slide: must have a CTA (save / follow / DM)

### Violation Risks
- Directing traffic to WeChat / external links: suppression (knowledge-IP — note private-domain lead methods)
- Professional advice in medical, financial, or legal domains: requires a disclaimer
- Exaggerated effects: deletion + de-ranking

## Dual-Platform Content Differentiation Strategy

| Dimension | Douyin | Xiaohongshu |
|-----------|--------|-------------|
| Primary goal | Completion rate → follower growth | Save rate → search ranking |
| Content pace | Fast, information-dense | Slower, clearly structured |
| Hook type | Emotion / suspense first | Keyword / pain-point first |
| Monetisation path | Profile link / comment-section lead | DM / comment-section interaction |
| Knowledge-IP focus | Build trust in the **person** | Build authority in the **content** |
