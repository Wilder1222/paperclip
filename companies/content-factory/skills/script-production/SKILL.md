# 脚本生产技能

## 能力范围

本技能为 Agent 提供完整的内容生产能力，包括抖音口播脚本、小红书图文文案和视频分镜文档的标准化输出。

---

## 口播脚本模板（抖音，60-180 秒）

```
【脚本基本信息】
选题：
时长预估：X 秒
钩子类型：反认知/痛点/悬念/利益/身份/数字
目标受众：

【第 0-3 秒 开场钩子】
（口语化，直接，无废话）
台词：___

【第 4-20 秒 问题建立】
（建立场景，让受众感到"说的就是我"）
台词：___

【第 21-80 秒 核心内容】
（干货递进，每 15-20 秒一个信息节点）
节点1（第 21-40 秒）：___
节点2（第 41-60 秒）：___
节点3（第 61-80 秒）：___

【第 81-120 秒 深化/案例】
（具体案例或亲身经历，增强可信度）
台词：___

【第 121-150 秒 互动问题引入】
（自然嵌入，引导评论）
台词："[互动问题]？欢迎在评论区告诉我。"

【最后 10 秒 CTA】
（清晰的下一步行动）
台词：___
```

**口播脚本写作规则**：
- 每句话 ≤ 20 字，口语化，无书面语
- 避免连续超过 3 个抽象概念，必须给具体例子
- 数字和对比是最强的说服工具（"3 年前 vs 现在"）
- 结尾 CTA 必须是"立即可做的一个动作"

## 图文文案模板（小红书，8-12 张）

```
【封面（第 1 张）】
主文字：[≤10 字，核心价值主张]
副文字：[补充说明，可选]
风格：大字/信息图/真人出镜

【第 2 张 引入痛点/场景】
文字：[描述受众共鸣场景，2-3 句话]
视觉：

【第 3-N 张 干货内容（每张一个要点）】
要点标题：[简洁明确]
说明文字：[3-5 句话，具体可操作]
视觉提示：

【末图 CTA（最后 1 张）】
引导文字：[收藏备用 / 关注获取更多 / 私信获取资料]
账号信息：[选填]
```

**正文文案结构（放在笔记描述栏）**：
```
[开场] 1-2 句戳痛点
[分点干货] 每点加 emoji，简洁
① [要点1]：[说明]
② [要点2]：[说明]
③ [要点3]：[说明]
[收尾] 互动引导问题
[标签] #话题1 #话题2 #话题3
```

## 知识 IP 内容结构模型

### 模型 1：问题-原因-方案（最通用）
1. 提出受众真实问题 → 2. 揭示根本原因（反常识更好） → 3. 给出可操作解决方案

### 模型 2：错误-代价-正确做法
1. 指出常见错误 → 2. 说明持续这样做的代价 → 3. 给出正确方法

### 模型 3：故事-转折-方法论
1. 讲一个真实经历/故事 → 2. 关键转折点 → 3. 提炼可复用的方法

### 模型 4：清单型（高收藏）
1. 直接给出 X 个要点 → 2. 每个要点加具体说明和例子 → 3. 总结核心规律

## 质量检查清单

- [ ] 钩子是否在前 5 字内抓住注意力？
- [ ] 每个干货点是否有具体例子支撑（不只是概念）？
- [ ] 互动问题是否自然嵌入（不突兀）？
- [ ] CTA 是否明确（一个动作，不是多个）？
- [ ] 全文是否通过合规检查（无敏感词/夸大承诺）？
- [ ] 小红书文案是否含有 2-3 个搜索关键词？
