# Script Production Skill

## Scope

This skill gives agents complete content-production capability, including standardised output of Douyin voiceover scripts, Xiaohongshu graphic copy, and video storyboard documents.

---

## Voiceover Script Template (Douyin, 60–180 seconds)

```
[Script Metadata]
Topic:
Estimated length: X sec
Hook type: counter-intuitive / pain-point / suspense / benefit / identity / number
Target audience:

[0–3 sec  Opening Hook]
(Conversational, direct, no filler)
Dialogue: ___

[4–20 sec  Problem Setup]
(Build the scene — make the audience feel "this is about me")
Dialogue: ___

[21–80 sec  Core Content]
(Dry goods build progressively; one information node every 15–20 sec)
Node 1 (21–40 sec): ___
Node 2 (41–60 sec): ___
Node 3 (61–80 sec): ___

[81–120 sec  Deep-Dive / Case Study]
(Concrete example or personal experience — adds credibility)
Dialogue: ___

[121–150 sec  Engagement Question Lead-In]
(Naturally embedded; prompts comments)
Dialogue: "[Engagement question]? Let me know in the comments."

[Last 10 sec  CTA]
(Clear next action)
Dialogue: ___
```

**Voiceover Script Writing Rules**:
- Every sentence ≤ 20 words, conversational register, no written-style long sentences
- Never stack more than 3 abstract concepts in a row — always give a concrete example
- Numbers and contrasts are the most powerful persuasion tools ("3 years ago vs now")
- Ending CTA must be "one action the audience can take right now"

## Graphic Copy Template (Xiaohongshu, 8–12 slides)

```
[Cover (Slide 1)]
Main text: [≤ 10 words, core value proposition]
Sub-text: [supplementary note, optional]
Style: large text / infographic / on-camera

[Slide 2  Pain Point / Scene Intro]
Text: [describe a resonant audience scenario, 2–3 sentences]
Visual:

[Slides 3–N  Dry-Goods Content (one key point per slide)]
Point title: [concise and clear]
Explanation: [3–5 sentences, specific and actionable]
Visual cue:

[Last Slide  CTA]
Lead text: [save for later / follow for more / DM for resources]
Account info: [optional]
```

**Body Copy Structure (for the note description field)**:
```
[Opening] 1–2 sentences hitting the pain point
[Bullet-point dry goods] One emoji per point, concise
① [Point 1]: [explanation]
② [Point 2]: [explanation]
③ [Point 3]: [explanation]
[Closing] Engagement-guiding question
[Hashtags] #topic1 #topic2 #topic3
```

## Knowledge-IP Content Structure Models

### Model 1: Problem → Cause → Solution (Most Versatile)
1. State the audience's real problem → 2. Reveal the root cause (counter-intuitive is better) → 3. Give an actionable solution

### Model 2: Mistake → Cost → Correct Approach
1. Point out the common mistake → 2. Explain the cost of continuing → 3. Give the right method

### Model 3: Story → Turning Point → Methodology
1. Tell a true experience / story → 2. The key turning point → 3. Extract a reusable method

### Model 4: List (High Save Rate)
1. Directly give X key points → 2. Each point with specific explanation and example → 3. Summarise the core pattern

## Quality Checklist

- [ ] Does the hook grab attention within the first 5 words?
- [ ] Does each dry-goods point have a concrete example (not just a concept)?
- [ ] Is the engagement question naturally embedded (not jarring)?
- [ ] Is the CTA clear (one action, not multiple)?
- [ ] Has the entire piece passed compliance check (no prohibited words / exaggerated promises)?
- [ ] Does the Xiaohongshu copy include 2–3 search keywords?
