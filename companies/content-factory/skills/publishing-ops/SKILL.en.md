# Publishing Operations Skill

## Scope

This skill gives agents complete dual-platform content publishing capability, including optimal timing selection, hashtag system, A/B title test strategy, and first-comment interaction operations.

---

## Publish Timing Strategy (Knowledge-IP Account)

### Douyin Optimal Timing

| Window | Time | Best Content Type |
|--------|------|------------------|
| Midday | 12:00–13:00 | Light / quick dry-goods |
| Prime evening | 20:00–22:00 | In-depth knowledge / story content |
| Morning | 07:00–08:30 | Career / productivity knowledge |

**Note**: Weekday evenings (Tue–Thu 20:00) are typically the highest-interaction window for knowledge-IP content.

### Xiaohongshu Optimal Timing

| Window | Time | Best Content Type |
|--------|------|------------------|
| Morning | 08:00–09:00 | Commute / pre-wake browsing |
| Midday | 12:00–13:30 | Lunch-break micro-sessions |
| Evening | 21:00–22:30 | Pre-sleep deep browsing |

**Note**: Xiaohongshu content has a longer lifecycle than Douyin; search traffic continues entering 3–7 days after publishing.

## Hashtag Strategy

### Douyin Hashtag Set (3–5 per piece)
- **#1**: Platform-level trending topic (high traffic, e.g. #KnowledgeSharing #Workplace #Learning)
- **#2–3**: Vertical-specific topics (content-relevant, e.g. #WorkplaceCommunication #TimeManagement)
- **#4**: Account-branded topic (builds content series feel, e.g. #AccountNameDailyKnowledge)
- **#5 (optional)**: Location / trending event hashtag (traffic riding)

### Xiaohongshu Hashtag Set (3–5 per piece)
- **#1**: Search keyword (a term users actively search for)
- **#2–3**: Vertical content topics
- **#4**: Account-branded tag
- **Prohibited**: #recommendations #musthave and similar topics misaligned with content (reduces precision targeting)

## A/B Title Test Strategy

### Test Rules
- Prepare 2 titles per piece (A primary / B backup)
- After 72 hours: observe click-through rate and completion rate
- If title A is significantly below account average after 72 hours, switch to title B
- Record every test result; accumulate high-converting title patterns

### Douyin Title A/B Principles
- Version A: emotion-driven (pain-point / counter-intuitive)
- Version B: benefit-driven (learn and get X)

### Xiaohongshu Title A/B Principles
- Version A: search keyword priority (contains precise keyword phrase)
- Version B: emotional resonance priority (touches audience psychology)

## First-Comment Operations SOP

Execute within **5 minutes** of publishing:

### Douyin First-Comment Templates
```
[Engagement-guiding]: Has this ever happened to you? Tell me in the comments 👇
[Dry-goods supplement]: One thing I didn't have time to say in the video: [1 sentence of dry goods] — save it ⭐
[Question prompt]: [The engagement question from the video] — looking forward to your answer!
```

### Xiaohongshu First-Comment Templates
```
[Save reminder]: Save it first — easy to find when you need it 📌
[Engagement-guiding]: Chat in the comments: [specific scenario question]?
[Series preview]: Next post covers [related topic] — follow so you don't miss it ✅
```

### First-Comment Principles
- First comment must have substantive content (posting only "follow me" is not allowed)
- Knowledge-IP first comment should prioritise adding dry goods or prompting discussion (builds professional image)
- Reply to the first 10 user comments (algorithm signal + community atmosphere)

## Pre-Publishing Final Checklist

- [ ] Does the title include the core keyword?
- [ ] Is the cover text legible on a small mobile screen?
- [ ] Is the hashtag count within 3–5?
- [ ] Is the publish time in the optimal window?
- [ ] Is the first-comment copy ready?
- [ ] Has the compliance check passed (no prohibited words / exaggerated promises)?
- [ ] Does the video / image post meet quality standards (clarity / ratio / subtitles)?
