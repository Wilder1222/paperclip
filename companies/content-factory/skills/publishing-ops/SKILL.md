# 发布运营技能

## 能力范围

本技能为 Agent 提供双平台内容发布的完整操作能力，包括最优时段选择、标签体系、A/B 标题测试策略和首评互动运营。

---

## 发布时段策略（知识 IP 账号）

### 抖音最优发布时段

| 时段 | 时间 | 适用内容 |
|------|------|---------|
| 午间 | 12:00-13:00 | 轻松/快速干货类 |
| 晚间黄金 | 20:00-22:00 | 深度知识/故事类 |
| 早间 | 07:00-08:30 | 职场/效率类知识 |

**注意**：工作日晚间（周二-周四 20:00）通常是知识类内容最高互动时段。

### 小红书最优发布时段

| 时段 | 时间 | 适用内容 |
|------|------|---------|
| 早间 | 08:00-09:00 | 通勤/起床前浏览 |
| 午间 | 12:00-13:30 | 午休碎片时间 |
| 晚间 | 21:00-22:30 | 睡前深度浏览 |

**注意**：小红书内容生命周期比抖音长，搜索流量会在发布后 3-7 天持续进入。

## 标签策略（话题体系）

### 抖音标签组合（每条内容 3-5 个）
- **第1个**：平台级热门话题（流量大，如 #知识分享 #职场 #学习）
- **第2-3个**：垂类精准话题（内容相关，如 #职场沟通 #时间管理）
- **第4个**：账号专属话题（建立内容系列感，如 #账号名每日知识）
- **第5个（可选）**：地域/热点话题（蹭流量）

### 小红书标签组合（每条内容 3-5 个）
- **第1个**：搜索热词（用户会主动搜的词）
- **第2-3个**：垂类内容话题
- **第4个**：账号专属标签
- **禁止**：#好物推荐 #种草 等与内容不符的话题（降低精准度）

## A/B 标题测试策略

### 测试规则
- 每条内容准备 2 个标题（A 主标题 / B 备选标题）
- 发布后 72 小时：观察点击率和完播率
- 如果 A 标题 72 小时内数据显著低于账号平均值，切换到 B 标题
- 记录每次测试结果，积累高转化标题规律

### 抖音标题 A/B 原则
- A 版：情绪驱动型（痛点/反认知）
- B 版：利益驱动型（学完得到 X）

### 小红书标题 A/B 原则
- A 版：搜索关键词优先（含精准词组）
- B 版：情绪共鸣优先（戳受众心理）

## 首评运营 SOP

发布后 **5 分钟内** 执行：

### 抖音首评模板
```
[互动引导型]：你们有没有遇到过这种情况？评论区说说看 👇
[干货补充型]：补充一个视频没来得及说的点：[1 句干货]，收藏备用 ⭐
[问题引导型]：[视频中的互动问题]，期待你的答案！
```

### 小红书首评模板
```
[收藏提醒型]：建议先收藏，用到的时候方便找 📌
[互动引导型]：评论区聊聊：[具体场景问题]？
[系列预告型]：下一篇讲 [相关话题]，记得关注不错过 ✅
```

### 首评运营原则
- 首评必须有实质内容（不允许只发"关注我" 这类空洞评论）
- 知识 IP 首评优先补充干货或引导讨论（建立专业形象）
- 回复前 10 条用户评论（算法信号 + 社区氛围建设）

## 内容发布前最终检查清单

- [ ] 标题是否包含核心关键词？
- [ ] 封面文字是否清晰可读（手机小屏测试）？
- [ ] 标签数量是否在 3-5 个范围内？
- [ ] 发布时间是否在最优时段？
- [ ] 首评文案是否准备好？
- [ ] 合规检查是否通过（无违禁词/夸大承诺）？
- [ ] 视频/图文质量是否达标（清晰度/比例/字幕）？
