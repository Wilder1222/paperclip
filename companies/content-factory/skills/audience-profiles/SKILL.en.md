## Dual-Platform Audience Behaviour Comparison

| Dimension | Douyin Behaviour | Xiaohongshu Behaviour |
|-----------|-----------------|----------------------|
| Entry motive | Passively discovered via recommendation; scattered attention | Actively searching; has a clear need |
| Retention judgement | First 3 seconds; triggered by emotion / suspense | Cover + title; keyword match |
| Interaction style | Likes, completion, emotional comments | Saves (study later), comment questions |
| Follow motive | "This person is interesting / valuable — I want to keep watching" | "This account has systematic dry goods — worth following" |
| Conversion path | Profile → DM → paid | Comment section → DM → paid |

## Usage Rules

- **trend-researcher**: Every topic's "audience pain point" field must correspond to a specific pain-point category in this file
- **script-writer**: Before choosing a hook type, cross-check this file to confirm the hook hits a core audience pain or desire
- **growth-analyst**: Update audience behaviour observations once per month (based on comment section, DM, completion-rate data); submit to human for approval
- **Update cadence**: First 30 days after account launch — update weekly based on real data; monthly thereafter
