# Analytics Review Skill

## Scope

This skill gives agents systematic content-data analysis capability, including core metric definitions, periodic review frameworks, and the keep/stop/try three-part decision tool.

---

## Core Metric System (Knowledge-IP)

### Douyin Core Metrics

| Metric | Calculation | Healthy Value (Knowledge-IP) | Notes |
|--------|------------|------------------------------|-------|
| Completion rate | Full-view count / total views | ≥ 35% | Most important algorithm signal |
| Interaction rate | (likes + comments + saves) / views | ≥ 5% | Overall interaction performance |
| Follow conversion rate | New follows / views | ≥ 0.5% | Core account-growth metric |
| Save rate | Saves / views | ≥ 2% | Knowledge-content value signal |
| Share rate | Shares / views | ≥ 1% | Content propagation power |

### Xiaohongshu Core Metrics

| Metric | Healthy Value (Knowledge-IP) | Notes |
|--------|------------------------------|-------|
| Save rate | ≥ 10% | Most critical metric — represents practical value of content |
| Interaction rate | ≥ 8% | Includes likes + comments + saves |
| Search traffic share | ≥ 40% | High search share = keyword strategy working |
| Follow conversion | ≥ 2% | Profile visit → follow conversion |

## Keep / Stop / Try Review Framework

### Keep
**Definition**: Data above account average for 2+ consecutive weeks, or a single piece that hits the viral threshold.

**Analysis dimensions**:
- Topic angle (what types of topics consistently work?)
- Content format (voiceover / graphics / remix — which has higher completion rate?)
- Hook type (which opening hook drives higher completion?)
- Publish timing (what time window gets better interaction?)
- Hashtag topics (which topic brings more precise traffic?)

**Action**: Formalise "Keep" directions as SOPs; add to topic standards and script templates.

---

### Stop
**Definition**: 3+ consecutive pieces of the same type underperforming the account average by 20%+, with no improvement.

**Analysis dimensions**:
- Topic fatigue (has this topic exhausted the audience's appetite?)
- Format obsolescence (is this content format no longer being recommended on that platform?)
- Timing mismatch (does publish time not align with audience active hours?)
- Increased competition (is the topic niche too crowded?)

**Action**:
- Immediately stop producing new content in that direction
- Analyse failure reasons and log to "No-Go List"
- Find a differentiated alternative direction

---

### Try
**Definition**: A new direction with a reasonable hypothesis but no verified data — needs 2–3 pieces for conclusions.

**Experiment design principles**:
- Change only one variable at a time (hook / topic angle / content format / publish time)
- Minimum 2 pieces per experiment period
- Define "success" and "failure" data standards before starting the experiment

**Experiment Template**:
```
Hypothesis: [If I do XXX, then YYY will improve because ZZZ]
Test content: [What specifically to do]
Test period: [Number of pieces, number of weeks]
Success criteria: [Specific numbers]
Failure exit criteria: [Specific numbers]
```
