# 数据分析与复盘技能

## 能力范围

本技能为 Agent 提供系统化的内容数据分析能力，包括核心指标定义、周期性复盘框架和"继续做/停止做/实验做"三分法决策工具。

---

## 核心指标体系（知识 IP）

### 抖音核心指标

| 指标 | 计算方式 | 健康值（知识 IP） | 说明 |
|------|---------|---------------|------|
| 完播率 | 完整播放人数 / 播放总人数 | ≥ 35% | 最重要的算法信号 |
| 互动率 | (点赞+评论+收藏) / 播放量 | ≥ 5% | 综合互动表现 |
| 关注转化率 | 新关注 / 播放量 | ≥ 0.5% | 账号增长核心指标 |
| 收藏率 | 收藏数 / 播放量 | ≥ 2% | 知识内容价值信号 |
| 分享率 | 分享数 / 播放量 | ≥ 1% | 内容传播力 |

### 小红书核心指标

| 指标 | 健康值（知识 IP） | 说明 |
|------|---------------|------|
| 收藏率 | ≥ 10% | 最核心指标，代表内容实用价值 |
| 互动率 | ≥ 8% | 含点赞+评论+收藏 |
| 搜索占比 | ≥ 40% | 高搜索占比说明关键词策略有效 |
| 关注转化 | ≥ 2% | 主页访问→关注转化 |

### 爆款判定标准（可按账号量级调整）

| 账号量级 | 抖音爆款阈值 | 小红书爆款阈值 |
|---------|------------|-------------|
| 1 万粉以下 | 播放 ≥ 5 万 | 展现 ≥ 1 万 |
| 1-10 万粉 | 播放 ≥ 20 万 | 展现 ≥ 5 万 |
| 10 万粉以上 | 播放 ≥ 100 万 | 展现 ≥ 20 万 |

## 三分法复盘框架

### 继续做（Keep）
**定义**：连续 2 周以上数据高于账号平均值，或单条内容达到爆款标准。

**分析维度**：
- 选题角度（什么类型选题持续有效？）
- 内容形式（口播/图文/混剪，哪种完播率更高？）
- 钩子类型（哪种开场钩子带来更高完播？）
- 发布时段（什么时间段互动率更好？）
- 话题标签（哪个话题带来了更多精准流量？）

**操作**：将"继续做"的方向形成 SOP，纳入选题标准和脚本模板。

---

### 停止做（Stop）
**定义**：连续 3 条以上同类内容数据低于账号平均值 20%+，无改善迹象。

**分析维度**：
- 选题疲劳（该话题受众已经审美疲劳？）
- 形式失效（某种内容形式在该平台不再受推荐？）
- 时段问题（发布时间与受众活跃时间不符？）
- 竞争加剧（该话题赛道过于拥挤？）

**操作**：
- 立即停止该方向的新内容生产
- 分析失败原因并记录到"禁区清单"
- 寻找差异化的替代方向

---

### 实验做（Try）
**定义**：有合理假设但尚未验证的新方向，需要 2-3 条内容数据支撑结论。

**实验设计原则**：
- 每次只改变一个变量（钩子 / 选题角度 / 内容形式 / 发布时间）
- 实验周期不少于 2 条内容
- 明确定义"成功"和"失败"的数据标准（实验前确定）

**实验模板**：
```
假设：[如果我做 XXX，那么 YYY 会改善，因为 ZZZ]
测试内容：[具体做什么]
测试周期：[几条内容，几周]
成功标准：[具体数字]
失败退出标准：[具体数字]
```
