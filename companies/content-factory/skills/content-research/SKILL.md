# 内容研究技能

## 能力范围

本技能赋予 Agent 系统化研究内容方向的能力，包括：

1. **热点追踪**：从抖音热榜、小红书发现页、微博热搜、百度指数等平台获取实时热点，识别趋势生命周期（上升期/顶峰期/衰退期）
2. **竞品拆解**：分析同赛道 Top 账号的高播放内容，提取选题规律、钩子模式、内容结构
3. **关键词聚类**：按"痛点词 / 欲望词 / 场景词"三类建立并维护关键词库

## 选题评估框架

每条候选选题必须通过以下维度评估：

| 维度 | 评估问题 | 输出格式 |
|------|---------|---------|
| 受众痛点 | 目标用户最真实的困扰/欲望是什么？ | 1 句话精准描述 |
| 平台适配 | 这个选题更适合抖音（完播驱动）还是小红书（搜索收藏驱动）？ | 选择 + 1 句理由 |
| 内容角度 | 最适合哪种角度切入？ | 情绪锚/痛点揭示/反认知/干货清单/故事叙事 |
| 素材来源 | 数据/案例从哪里来？ | 热搜词/竞品案例/行业数据/原创视角 |
| 风险点 | 合规风险/平台限流风险/受众反感风险？ | 无则填"无"，有则给替代方案 |
| 完播率预判 | 同类内容历史数据判断 | 高/中/低 |

## 关键词库维护规则

- 每周更新一次，新增来自热搜/竞品/评论区高频词
- 按三类标注：痛点词（用户困扰）/ 欲望词（用户渴望）/ 场景词（使用情境）
- 知识 IP 专属词优先：[行业术语] / [方法论名词] / [受众角色词]
- 标注各词在平台的搜索热度趋势（上升/平稳/下降）
