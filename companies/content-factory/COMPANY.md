# 自媒体内容工厂

自媒体内容工厂是一家由 AI Agent 驱动的双平台内容公司，覆盖抖音与小红书，目标是通过标准化流水线实现高频、高质内容输出，并将内容流量转化为私域与成交。

## 工作流（流水线模式）

```
业务目标 + 账号定位 + 素材库
         ↓
[阶段1] 选题  ── trend-researcher → strategy-lead 审核
         ↓
[阶段2] 脚本  ── script-writer → strategy-lead 审核
         ↓
[阶段3] 制作  ── video-producer → publisher-operator 接收
         ↓
[阶段4] 发布  ── publisher-operator 按平台规范发布 + 首评运营
         ↓
[阶段5] 复盘  ── growth-analyst → ceo + strategy-lead 接收周报
```

## 组织架构

| Agent | 职务 | 汇报对象 |
|-------|------|---------|
| ceo | 内容公司负责人 | — |
| strategy-lead | 内容战略与选题负责人 | ceo |
| trend-researcher | 热点/竞品/关键词研究 | strategy-lead |
| script-writer | 脚本与文案 | strategy-lead |
| video-producer | 视频/图文制作说明 | strategy-lead |
| publisher-operator | 发布与排期运营 | ceo |
| growth-analyst | 数据分析与复盘 | ceo |

## 战略目标（90 天）

- **目标 A（增长）**：抖音 + 小红书总粉丝净增 20k
- **目标 B（产能）**：每周稳定产出 20 条短内容（短视频/图文混合）
- **目标 C（质量）**：爆款率（完播+互动达标）≥ 15%
- **目标 D（商业化）**：建立"内容→私域/成交"闭环，形成标准转化链路
