Based on cold-start data, produce a "Prompt Template Library" covering the main topic types for daily use by trend-researcher, script-writer, and video-producer — reducing repetitive thinking overhead and improving production efficiency.

## Task Goal

Solidify the content directions, hook patterns, and script structures validated during the cold-start phase into reusable prompt templates.

## Template Library Must Include

1. **Topic-related templates** (for trend-researcher)
   - Trending topic mining prompt template
   - Competitor analysis prompt template
   - Keyword clustering prompt template

2. **Script templates** (for script-writer)
   - Dry-goods list script template
   - Story narrative script template
   - Counter-intuitive script template
   - Xiaohongshu image-post copy template

3. **Hook library** (extension for hook-writing skill)
   - 30 validated effective hooks categorised by topic type

4. **Production spec templates** (for video-producer)
   - Voiceover video production package template
   - Xiaohongshu image-post production package template

## Acceptance Criteria

- All templates reviewed by strategy-lead
- Every template includes a usage guide and example
- trend-researcher and script-writer confirm "ready to use as-is"

## Submission Deadline

Within 3 working days of the cold-start first-week review completion.
