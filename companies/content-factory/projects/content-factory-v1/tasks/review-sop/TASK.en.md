Produce a "Content Data Review Standard Operating Procedure (SOP)" that standardises the data collection, analysis, and keep/stop/try recommendation process for the weekly report.

## Task Goal

Standardise the review workflow to ensure consistent weekly report quality, auditable data analysis, and strategy recommendations the CEO and strategy-lead can act on directly.

## SOP Must Include

1. **Data collection checklist** (list of metrics to collect per piece, separated by platform)
2. **Weekly report data entry template** (standardised table format)
3. **Viral breakdown analysis template** (per-segment analysis framework)
4. **Keep/stop/try decision tree** (quantitative criteria for when to keep / stop / try)
5. **OKR progress calculation formula** (ensures consistent calculation method week over week)
6. **Data anomaly handling protocol** (analytical framework for diagnosing data fluctuation causes)

## Acceptance Criteria

- strategy-lead and CEO sign off
- growth-analyst outputs weekly reports per SOP for 2 consecutive weeks; feedback confirms "directly actionable"
- Document contains specific numeric standards — vague phrases like "depends on situation" are not allowed

## Submission Deadline

Within 3 working days of the cold-start first-week review completion.
