# Pipeline Standardisation Project

This project formalises the content directions, script patterns, and publishing strategies validated during cold start into standardised processes, establishing a sustainable 20-piece-per-week content production system.

## Delivery Milestones

1. **M1 (Week 2)**: Prompt template library complete (iterated from first-batch content data)
2. **M2 (Week 2)**: Publishing SOP document finalised
3. **M3 (Week 3)**: Review SOP document finalised
4. **M4 (Week 4)**: Quality scorecard live and in use

## Success Criteria

- Any new agent can independently complete the topic / script / publishing workflow using the SOP documents
- Prompt template library covers ≥ 80% of standard topic types
- Quality scorecard approved by strategy-lead
- Weekly output consistently reaches 20 pieces (for 2 consecutive weeks)
